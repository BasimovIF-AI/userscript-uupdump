# Changelog

Все изменения в проекте документируются в соответствии со спецификацией [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и принципами [Semantic Versioning](https://semver.org/).

## [1.3.0] - 2026-10-24

### Added
- Новая фасетная группа **«Категория»** (`packageCategory`) выведена **первым (верхним) пунктом панели**:
  - Разделяет все элементы на два фундаментальных класса: **«Полные сборки»** (установочные образы Windows / Feature Updates) и **«Обновления»** (накопительные пакеты, .NET Framework, Preview, Security Updates).
  - В один клик позволяет отсеять все апдейты и оставить только образы ОС, либо наоборот — сфокусироваться только на пакетах обновлений.
  - Полная поддержка динамического пересчета: при выборе «Полные сборки» зависимые типы обновлений (.NET Framework, Cumulative, Preview) мгновенно показывают 0 и блокируются.

### Changed
- Обновлен набор unit-тестов [`test_filter_engine.js`](file:///e:/Ильгиз/Documents/VibeCoding/TM_Scripts/userscript-uupdump/test_filter_engine.js) с проверкой классификации и взаимной фильтрации полных сборок и обновлений.

## [1.2.0] - 2026-10-24

### Added
- Группа фильтрации **«Сборка (Build)»** переведена в компактный Semantic UI выпадающий список (`<select>`) с опцией по умолчанию «Все сборки (Всего: N)» и мини-кнопкой сброса `[✖]`.
- **Динамический пересчет счетчиков фасетов (Dynamic Context Recalculation):** при выборе любого фильтра счетчики во всех остальных группах динамически пересчитываются на основе оставшихся подходящих сборок.
- **Блокировка нерелевантных опций:** если при текущей комбинации фильтров количество сборок для чипа становится равным 0, кнопка отключается (`disabled`), становится полупрозрачной (`opacity: 0.35`) и недоступной для клика.
- В выпадающем списке сборок опции с 0 подходящих сборок автоматически помечаются как `disabled`.

## [1.1.0] - 2026-10-24

### Added
- Новая динамическая фасетная группа **«Сборка (Build)»** (`buildNumber`): позволяет фильтровать строки по точным номерам сборок и ревизий.
- Численная сортировка номеров сборок по убыванию.
- Полноценная классификация пакетов **.NET Framework**: отдельный тип `.NET Framework Update` в фасете «Тип сборки».
- Интеллектуальный вывод версии ОС по номеру сборки (`26300` $\rightarrow$ `26H2` и др.).
- Автоматическое скрытие любой группы фильтров, если для нее нет элементов на текущей странице.
