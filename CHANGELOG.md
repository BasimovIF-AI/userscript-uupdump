# Changelog

Все изменения в проекте документируются в соответствии со спецификацией [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/) и принципами [Semantic Versioning](https://semver.org/).

## [1.4.0] - 2026-10-25

### Added
- **100% классификация по полному датасету (9 148 сборок):**
  - Просканированы и внесены в эталонную базу все 92 страницы каталога `known.php`.
  - Добавлена поддержка ОС: `Azure Stack HCI`, `Windows Holographic`, `Windows Team` (Surface Hub), `Windows CPC OS` (Cloud PC) и `Системные компоненты` (автономные .NET и Update Stack без ОС в заголовке).
  - Интеллектуальный fallback по номеру сборки исключил неопознанные ОС (0% `Другая ОС`).
  - Распознавание типов пакетов расширено поддержкой: `Update Stack Package`, `Autopilot Update`, `Setup Duo`, `Dynamic Update`.
  - Улучшена детекция версий сборок: поддержка сборок Windows Insider Canary (`25xxx`), Dev (`23xxx`, `21xxx`), Beta (`22635`, `22624`, `22623`), Server 2022 (`20348`) и ранних релизов Windows 10 (включая RTM `1507` и `1511`).
  - Логическая сортировка чипов: приоритетный порядок для Категории, Архитектуры, ОС и Версий (от самых свежих к старым).

### Fixed
- **Чистка фильтра веток разработки:**
  - Устранена коллизия: версии в скобках вроде `(1809)` и номера сборок вроде `(17763.1)` в накопительных обновлениях серверов больше не попадают в ветки разработки, а направляются строго в категории «Версия / Релиз» и «Сборка».

## [1.3.3] - 2026-10-24

### Fixed
- **Точное позиционирование на главной странице (`/` и `/index.php`):**
  - Панель фильтров теперь строго связывается с таблицей последних добавленных сборок (*Recently added builds*).
  - Блок быстрых кнопок/пресетов (`.home-quick-options`) явно исключен из детекции.
  - Введено обязательное условие обнаружения сборок: наличие ссылок `selectlang.php?id=` и не менее 2 строк данных в таблице.

### Added
- Расширен парсер версий и типов: добавлено распознавание сборок будущего/экспериментальных (`>= 28000` $\rightarrow$ `Future / Experimental`), а также обновлений типа `Quality Update`.

## [1.3.2] - 2026-10-24

### Fixed
- **Исключена ошибочная активация панели на страницах мастера загрузки:**
  - Добавлены директивы `@exclude` в заголовок Tampermonkey для страниц `selectedition.php`, `selectlang.php`, `get.php`, `downloadpack.php`, `findfiles.php`, `faq.php`.
  - Внедрена двухуровневая программная защита: проверка пути страницы (`isBuildsPage`) и сигнатурная валидация таблицы сборок (`isBuildsTable`).
  - Таблицы редакций (*Additional edition*) и языковых пакетов теперь полностью игнорируются, исключая появление панели фильтрации на шагах мастера скачивания.

### Changed
